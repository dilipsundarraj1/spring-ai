Can # Spring AI Course

A teaching repository: each module demonstrates one area of Spring AI, with working endpoints and a README that
explains the trade-offs rather than just the API.

## Language

### Chat memory

**Turn**:
A single raw message in a conversation, exactly as typed by the person or generated by the model.
_Avoid_: message, line, exchange

**Chat Memory**:
The bounded set of recent Turns replayed to the model so it appears to remember. Older Turns are dropped.
_Avoid_: history, context window

**Chat History**:
The complete record of every Turn. Never trimmed, never sent to the model; read for audits and to re-derive
Long-Term Memory.
_Avoid_: memory, log

**Long-Term Memory**:
The durable store of Profile Facts and Topic Summaries. Unlike Chat History it is sent to the model, and unlike
Chat Memory it is never trimmed.
_Avoid_: vector memory, semantic memory

**Profile Fact**:
A short keyed assertion about the person, derived from Turns rather than quoted from them. One per key, replaced
when the person corrects it.
_Avoid_: fact, attribute, preference

**Topic Summary**:
A self-contained note covering several Turns on one subject, derived rather than quoted. Accumulates; never replaced.
_Avoid_: summary, note, digest

**Consolidation**:
Turning Turns into Profile Facts and Topic Summaries as they leave Chat Memory. The Turns themselves survive in
Chat History, so Consolidation can be re-run later against different rules.
_Avoid_: extraction, compaction, summarisation

**User**:
The person the application serves, and the owner of Long-Term Memory. Distinct from the `USER` message role, which
marks a Turn the person authored rather than the person themselves.
_Avoid_: person, account, customer, profile

**Conversation ID**:
The identifier that scopes one conversation's Chat Memory, keeping one person's conversation out of another's.
_Avoid_: session id, thread id
